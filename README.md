# STM32F103 OTA Workspace

This repository contains three independent STM32F103 projects:

- `bootloader/`: IAP bootloader and dual-partition layout.
- `app1/`: Application project with the current IAP/update command flow.
- `app2/`: Second application project.

Each directory is a self-contained CubeMX/Keil project. Pull the repository
once to get all three projects on another computer.
